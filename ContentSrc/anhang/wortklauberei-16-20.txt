## Das Suffix -tor
Das Suffix -tor bezeichnet immer den „Täter“, also den Ausführenden einer Handlung. Nomina auf -tor sind meistens von einem Verbum abgeleitet.
?? Was bedeuten orator, spectator, amator, imperator – und welche Verba stecken darin? => orator = Redner (orare = reden; auch bitten, beten); spectator = Zuschauer (spectare = anschauen); amator = Liebhaber (amare = lieben); imperator = Feldherr, Kaiser (imperare = befehlen).
## Das Suffix -tio
Das Suffix -tio drückt eine Handlung aus (lat. actio, -ionis = „Tätigkeit“; engl. action). Der orator ist der „Täter“ (Redner), die oratio die Handlung selbst (Rede).
?? Was könnten traditio, laudatio, auctio und contentio bedeuten? => traditio = Übergabe, Überlieferung (tradere = übergeben, überliefern); laudatio = Lobrede, Lob (laudare = loben); auctio = Vermehrung, Versteigerung (augere = vermehren); contentio = Anstrengung, Wettkampf, Streit (contendere = eilen, kämpfen).
## Das Suffix -tas
Wie -tudo drückt auch -tas eine Eigenschaft aus (auctoritas, -atis = „das Ansehen“). Nomina auf -tas sind immer feminin.
?? Was bedeuten libertas, potestas, cupiditas, nobilitas, atrocitas, improbitas? => libertas = Freiheit; potestas = Macht; cupiditas = Begierde, Gier; nobilitas = Adel (nobilis = adelig); atrocitas = Grausamkeit, Wildheit (atrox = wild, grässlich); improbitas = Schlechtigkeit, Bosheit (improbus = schlecht).
## Überblick über die Suffixe -tor / -tio / -tas / -tudo
| | -tor | -tio | -tas | -tudo |
| Bedeutung | Täter | Handlung | Eigenschaft | Eigenschaft |
| Geschlecht | m. | f. | f. | f. |
| lat. Beispiel | auctor („Autor“) | actio („Handlung“) | libertas („Freiheit“) | solitudo („Einsamkeit“) |
| Französisch | auteur | action | liberté | solitude |
| Italienisch | autore | azione | libertà | solitudine |
| Spanisch | autor | acción | libertad | solitud |
## Eine „herrschsüchtige“ Wortfamilie
Eine besonders große Wortfamilie bilden die Wörter mit dem Stamm reg-, der immer mit „Herrschen“ und „Regieren“ zu tun hat.
?? Was bedeuten regnare, regnum, rex und regina? => regnare = herrschen, regieren; regnum = (König-)Reich, Herrschaft; rex = König; regina = Königin.
## Synonyme und Antonyme
Synonyme sind gleichbedeutende, Antonyme gegensätzliche Wörter.
?? Ergänze Deutsch, deutsches und lateinisches Antonym (Beispiel: facilis = leicht ↔ schwer = difficilis): bonus, multi, docere, pax, novus => bonus = gut ↔ schlecht = malus; multi = viele ↔ wenige = pauci; docere = lehren ↔ lernen = discere; pax = Friede ↔ Krieg = bellum; novus = neu ↔ alt = antiquus.
## Das G'frett mit dem -us!
Die Endung -us gibt es im Nominativ bei mehreren Deklinationen:
| 1.F. Sg. | 2.F. Sg. | Deklination |
| -us | -i | o-Dekl. m. |
| -us | -us | u-Dekl. m./f. |
| -us | -utis | 3. Dekl. f. |
| -us | -oris/-eris | 3. Dekl. n. |
?? Ordne zu: tempus, virtus, animus, vulnus, servitus, senatus, socius, opus, litus, casus, manus, discipulus, domus, facinus, genus => o-Dekl. (-i): animus, socius, discipulus. u-Dekl. (-us): senatus, casus, manus, domus. 3. Dekl. f. (-utis): virtus, servitus. 3. Dekl. n. (-oris/-eris): tempus, vulnus, opus, litus, facinus, genus.
## Wörter, die du nicht verwechseln solltest
?? Was bedeuten: coepi – cepi, vicerunt – vixerunt, posuit – potuit, more – morte, parat – paret? => coepi = ich habe begonnen – cepi = ich habe gefasst; vicerunt = sie haben gesiegt – vixerunt = sie haben gelebt; posuit = er hat gelegt/gestellt – potuit = er hat gekonnt; more = durch die Sitte – morte = durch den Tod; parat = er bereitet vor – paret = er gehorcht.
